### 🔥 Firebase 실시간 데이터베이스 연동! (2026-03-06)

#### 🎯 해결된 문제

**Before (문제):**
```
❌ 데이터가 사라짐 (브라우저 캐시 삭제 시)
❌ 직원 간 데이터 공유 불가
❌ 각자 자기 데이터만 보임
❌ 데이터 백업 어려움
```

**After (해결):**
```
✅ 데이터 영구 저장 (절대 사라지지 않음)
✅ 모든 직원이 같은 데이터 실시간 공유
✅ A직원이 등록하면 B직원 화면에 즉시 표시
✅ Firebase 자동 백업
✅ 완전 무료 (10GB/일까지)
```

#### 🚀 Firebase의 장점

**1️⃣ 실시간 동기화**
- A직원이 데이터 등록 → B직원 화면에 즉시 표시
- 동시 작업 가능 (충돌 없음)

**2️⃣ 데이터 영구 저장**
- 브라우저 캐시 삭제 → 데이터 안전
- PC 포맷 → 데이터 안전  
- 재배포 → 데이터 안전

**3️⃣ 무료!**
- 하루 10GB 무료 (중소기업 충분)
- 예: 하루 1만 건 데이터 등록 가능

### 📊 대시보드 게이지 차트 대폭 개선! (2026-03-06)

#### 🎯 실무 최적화 지표로 교체

**사용자 상황:**
- 3개월에 한 번씩 수입 (분기별 수입)
- 제품 품목 약 20개

**Before** (일반적인 지표):
```
❌ 최근 7일 불량 비율 → 3개월 주기에는 의미 없음
❌ 월간 변화 → 수입이 없는 달은 데이터 없음
```

**After** (실무 맞춤 지표):
```
✅ 제품별 불량률 TOP 3 → 20개 제품 중 문제 제품 즉시 파악
✅ 불량 유형별 분포 → 주요 불량 원인 파악 및 개선 방향 수립
```

#### 🏆 새로운 게이지 차트

**1️⃣ 제품별 불량률 TOP 3**
```
┌─────────────────────────────────┐
│  🏆 제품별 불량률 TOP 3          │
├─────────────────────────────────┤
│        12.5%                    │
│      차차핑 카메라               │
│                                 │
│  1위: 차차핑 | 2위: 하츄핑      │
│  3위: 라라핑                    │
└─────────────────────────────────┘
```
**활용 방법:**
- 불량률이 높은 제품 즉시 확인
- 다음 수입 시 해당 제품 검수 강화
- 공급업체와 협의 시 구체적 근거 자료
- 품목별 품질 관리 우선순위 결정

**2️⃣ 불량 유형별 분포**
```
┌─────────────────────────────────┐
│  📊 불량 유형별 분포             │
├─────────────────────────────────┤
│        45%                      │
│       외관 불량                  │
│                                 │
│  1위: 외관 | 2위: 기능          │
│  3위: 포장                      │
└─────────────────────────────────┘
```
**활용 방법:**
- 가장 많이 발생하는 불량 유형 파악
- 해당 유형 검수 프로세스 개선
- 공급업체에 구체적 개선 요청
- 불량 예방 활동 방향 수립

#### 📈 대시보드 차트 구성

**게이지 차트 (상단):**

| 순서 | 게이지 차트명 | 표시 값 | 색상 기준 | 활용도 |
|------|--------------|---------|----------|--------|
| 1 | 전체 평균 불량률 | 8.6% | 낮을수록 초록 | 전체 품질 수준 |

| 3 | 불량 유형별 분포 | 45% | 높을수록 빨강 | 주요 불량 원인 |

**분석 차트 (하단):**

| 차트명 | 타입 | 표시 내용 | 활용도 |
|--------|------|----------|--------|
| 📊 제품별 불량률 비교 | 가로 막대 | 전체 20개 제품의 불량률 순위 | 전체 제품 품질 순위 한눈에 파악 |
| 📈 불량 유형별 통계 | 원형 차트 | 유형별 발생 비율 | 주요 불량 원인 시각화 |

#### 🎯 제품별 불량률 비교 차트 (신규 추가!)

**차트 특징:**
```
📊 제품별 불량률 비교 (전체 20개 제품)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
차차핑 카메라    ████████████ 12.5% 🔴
하츄핑 카메라    ████████     8.0% 🟡
라라핑 카메라    ████         3.8% 🟢
티티핑 피규어    ███          2.5% 🟢
바로핑 문구      ██           1.2% 🟢

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
전체 제품이 불량률 높은 순으로 표시됩니다.
```

**색상 구분:**
- 🔴 빨강 (>10%): 심각 - 즉시 개선 필요
- 🟡 노랑 (5~10%): 주의 - 모니터링 필요
- 🟢 초록 (<5%): 양호 - 유지 관리

**실무 활용:**
1. **다음 수입 준비**: 상위 3개 제품 중점 검수
2. **공급업체 협의**: 빨간색 제품 개선 요청
3. **검수 강화**: 노란색 제품 체크리스트 추가
4. **우수 사례**: 초록색 제품 프로세스 벤치마킹

**차트 높이 자동 조정:**
- 제품 개수에 따라 차트 높이 자동 조정 (제품당 30px)
- 20개 제품 = 600px 높이
- 스크롤 없이 모든 제품 확인 가능

### 🎨 LOT별 상세 불량률 대시보드 UI 대폭 개선! (2026-03-06)

#### 📊 개선 사항

**Before** (가독성 문제):
```
❌ 글씨가 가로로 겹쳐 보임
❌ 컬럼 너비가 좁아서 데이터 확인 어려움
❌ 모바일에서 표시 문제
```

**After** (명확한 가독성):
```
✅ 테이블 최소 너비 1200px로 확대
✅ 각 컬럼별 최적 너비 설정 (LOT: 140px, 제품명: 180px, 수량: 110px 등)
✅ 폰트 크기 증가 (헤더 1.05rem, 본문 1rem)
✅ 패딩 증가 (18px~20px)로 여유 공간 확보
✅ white-space: nowrap으로 글씨 줄바꿈 방지
✅ 가로 스크롤 지원으로 작은 화면에서도 완벽 표시
✅ 반응형 디자인 적용 (1280px, 768px 브레이크포인트)
```

#### 🎯 컬럼별 최적화

| 컬럼명 | 최소 너비 | 정렬 | 특징 |
|--------|----------|------|------|
| LOT 번호 | 140px | 중앙 | Bold 처리 |
| 제품명 | 180px | 좌측 | Ellipsis로 긴 이름 처리 |
| 불량 건수 | 100px | 중앙 | "건" 단위 표시 |
| 불량 수량 | 110px | 중앙 | 빨간색 강조 (1.1rem) |
| 수입 수량 | 110px | 중앙 | "개" 단위 표시 |
| 불량률 | 100px | 중앙 | Bold, 1.15rem 크기 |
| 상태 | 120px | 중앙 | 색상 배지 (우수/주의/심각) |

#### 🎨 시각적 개선

- **헤더**: 보라색 그라데이션 배경, 흰색 글씨
- **합계 행**: 연한 회색 배경, 상단 3px 보라색 보더, 폰트 크기 1.15rem
- **hover 효과**: 살짝 확대 (scale 1.01), 그림자 효과
- **스크롤 컨테이너**: 둥근 모서리, 그림자, 부드러운 스크롤

### ✨ 불량률 월간 변화 게이지 추가 (2026-03-06)

#### 🎯 기능
**이번 달 vs 지난 달 불량률 비교**로 품질 개선/악화 추세를 한눈에 파악!

#### 📊 계산 방식
```javascript
지난 달 불량률 = (지난 달 불량 수량 / 지난 달 수입 수량) × 100
이번 달 불량률 = (이번 달 불량 수량 /이번 달 수입 수량) × 100

변화율 = ((이번 달 불량률 - 지난 달 불량률) / 지난 달 불량률) × 100

예시 1 (개선):
지난 달 불량률: 15%
이번 달 불량률: 12%
변화율 = ((12 - 15) / 15) × 100 = -20%
→ 20% 감소 (개선!) 🟢

예시 2 (악화):
지난 달 불량률: 10%
이번 달 불량률: 13%
변화율 = ((13 - 10) / 10) × 100 = +30%
→ 30% 증가 (악화!) 🔴
```

#### 🎨 표시 방식
| 변화율 | 표시 | 색상 | 의미 |
|--------|------|------|------|
| **감소 (음수)** | -20% | 🟢 초록 | 품질 개선 중 |
| **변화 없음** | 0% | 🟡 노랑 | 현상 유지 |
| **증가 (양수)** | +30% | 🔴 빨강 | 품질 악화 중 |

  - 🟡 40-80%: 평상시
  - 🔴 80-100%: 급증 (높음 = 나쁨)
  
- **불량률 월간 변화** ✨ NEW!: 이번 달 vs 지난 달 불량률 비교

  - 🔴 증가: 품질 악화 (나쁨)
  - 표시 예시: "-20%" (20% 감소), "+15%" (15% 증가)
  - 계산식: ((이번 달 불량률 - 지난 달 불량률) / 지난 달 불량률) × 100

## 게이지 차트 계산 방식

### 1. LOT당 평균 불량 개수 (역순 색상)
```
계산식: (총 불량 수량 ÷ 고유 LOT 수) ÷ 20 × 100
기준: 20개를 100%로 가정
의미: LOT별 평균 불량 발생 수준
색상: 낮을수록 초록색 (좋음) → 높을수록 빨간색 (나쁨)
예시: 95개 불량, 10개 LOT → 9.5개/LOT → 47.5% (노랑)
```

### 2. 최근 7일 불량 비율 (역순 색상)
```
계산식: (최근 7일 불량 건수 ÷ 전체 불량 건수) × 100
의미: 최근 불량 발생 트렌드
색상: 낮을수록 초록색 (개선) → 높을수록 빨간색 (악화)
해석: 
  - 0-40% 🟢: 최근 불량 감소, 개선 중
  - 40-80% 🟡: 지속적인 불량 발생
  - 80-100% 🔴: 최근 불량 급증, 주의 필요
```

### 3. 전체 품질 점수 (정순 색상)
```
계산식: 100 - (평균 불량 수량 × 10)
의미: 전반적인 품질 수준
색상: 높을수록 초록색 (좋음) → 낮을수록 빨간색 (나쁨)
해석:
  - 80-100% 🟢: 우수한 품질
  - 40-80% 🟡: 보통 품질
  - 0-40% 🔴: 품질 개선 필요
예시: 평균 3개/건 → 100 - 30 = 70점 (노랑)
```

### ⚠️ 문제 해결

#### 문제 1: 불량 등록 후 목록에 표시되지 않는 경우

**증상**: "불량 정보가 등록되었습니다" 메시지는 나오지만 목록에 데이터가 없음

**진단 방법**:
1. **F12 키를 눌러 개발자 도구 열기**
2. **Console 탭** 클릭
3. 아래와 같은 로그 확인:
   ```
   Creating defect with data size: XXXXX bytes
   Created defect: {id: "...", ...}
   Fetching defects from: tables/defects?limit=1000
   Fetched defects: N items
   ```

**원인 및 해결**:

| 원인 | 증상 | 해결 방법 |
|------|------|-----------|
| **사진/동영상 파일 너무 큼** | "Creating defect" 후 에러 또는 무응답 | • 사진 5MB 이하로 줄이기<br>• 사진 해상도 낮추기 (자동 리사이징됨)<br>• 동영상 10MB 이하, 30초 이하 권장 |
| **네트워크 지연** | 등록 성공하지만 목록 조회 시 데이터 없음 | • 페이지 새로고침 (F5)<br>• 목록 메뉴 다시 클릭 |
| **필수 항목 누락** | Console에 에러 메시지 | • 수입일자, 제품명, LOT 번호, 불량 유형, 수량 확인 |
| **API 응답 느림** | 오래 기다렸지만 목록 비어있음 | • Console에서 데이터 직접 확인:<br>`fetch('tables/defects?limit=10').then(r=>r.json()).then(console.log)`<br>• 데이터가 있으면 → 페이지 새로고침<br>• 데이터가 없으면 → 재등록 필요 |

#### 문제 2: 사진 업로드 실패

**증상**: "사진 업로드 중 오류가 발생했습니다" 알림

**원인 및 해결**:
- **파일 크기 초과 (5MB)**: 사진 해상도를 낮추거나 압축하세요
- **지원되지 않는 형식**: JPG, PNG, GIF만 지원됩니다
- **자동 리사이징 실패**: 파일이 손상되었거나 형식 문제 → 다른 사진 사용

**자동 리사이징 기능**:
- 최대 크기: 1200x1200px
- 포맷: JPEG
- 품질: 80%
- 효과: 파일 크기 70-90% 감소 (예: 5.2MB → 450KB)

#### 문제 3: 페이지 로딩 느림

**원인**: Base64 인코딩으로 인한 데이터 크기 증가

**권장 사항**:
- 사진: 720p (1280x720) 이하 해상도
- 동영상: 30초 이하, 720p 이하
- 한 번에 사진 3-5장 이하 첨부
- 필요한 파일만 첨부

#### 문제 4: PDF 보고서 한글 깨짐

**해결**: 현재 버전은 **html2canvas**를 사용하여 한글을 이미지로 변환하므로 깨짐 없음

## 사용 방법

### 1. 불량 등록
1. 좌측 메뉴에서 "불량 등록" 클릭
2. 필수 항목 입력 (수입일자, 제품명, LOT 번호, 불량 유형, 불량 수량)
3. 선택 항목 입력 (시즌, 모델명, 상세 내용 등)
4. 필요시 사진/동영상 첨부
5. "등록하기" 버튼 클릭

### 2. 불량 조회 및 필터링
1. "불량 목록" 메뉴 클릭
2. 필터 입력 (수입일자 범위, 제품명, LOT 번호, 불량 유형)
3. "필터 적용" 버튼 클릭
4. 정렬 옵션 선택하여 원하는 순서로 정렬
5. 행 클릭하여 상세 정보 확인

### 3. 불량 삭제
**개별 삭제:**
1. 목록에서 삭제하려는 항목의 "휴지통" 아이콘 클릭
2. 확인 메시지에서 "확인" 클릭

**일괄 삭제:**
1. 목록에서 삭제할 항목들의 체크박스 선택
2. 상단의 "선택 항목 삭제" 버튼 클릭
3. 확인 메시지에서 "확인" 클릭

### 4. 불량 수정
1. 목록에서 항목의 "보기" 버튼 클릭하여 상세 보기
2. "수정하기" 버튼 클릭
3. 정보 수정 후 "수정하기" 버튼 클릭

### 5. 엑셀 다운로드
- **전체 다운로드**: 목록 페이지에서 "엑셀 다운로드" 버튼
- **선택 다운로드**: 체크박스로 항목 선택 후 "선택 항목 다운로드" 버튼
- **요약 다운로드**: 요약 페이지에서 "요약 엑셀 다운로드" 버튼

### 6. PDF 보고서 생성
1. "보고서 출력" 메뉴 클릭
2. 옵션 선택:
   - **전체 불량 보고서**: 모든 불량 포함
   - **LOT별 빠른 보고서**: 카드에서 원하는 LOT 선택
   - **사용자 지정**: 필터 조건 입력
3. "PDF 보고서 생성" 버튼 클릭

## 문제 해결

### 사진/동영상이 업로드되지 않아요

- **파일 크기 제한**:
  - 사진: 5MB 이하
  - 동영상: 10MB 이하 권장
- **지원 형식**: 
  - 사진: JPG, PNG, HEIC 등 모든 이미지 형식
  - 동영상: MP4, MOV 등
- 용량이 큰 파일은 등록 전에 압축하세요
- 여러 개를 한 번에 선택 가능합니다

### 엑셀 다운로드가 작동하지 않아요
- 브라우저의 팝업 차단을 해제하세요
- XLSX 라이브러리가 로드되었는지 확인하세요

### PDF 한글이 깨지거나 표시되지 않아요
- ✅ **해결됨**: html2canvas를 사용하여 HTML을 이미지로 변환한 후 PDF에 삽입
- 모든 한글, 특수문자, 이모지가 완벽하게 표시됩니다
- 폰트, 색상, 레이아웃이 화면과 동일하게 출력됩니다
- 페이지가 길 경우 자동으로 A4 크기로 분할됩니다

### PDF 생성이 느려요
