다른 컴퓨터에서도 데이터를 실시간으로 공유하세요!

⚠️ 중요!
현재 LocalStorage를 사용하고 있어 각 컴퓨터의 브라우저에만 데이터가 저장됩니다.
Firebase를 설정하면 모든 컴퓨터에서 데이터를 실시간으로 공유할 수 있습니다!
1

Firebase Console 접속

Firebase Console에 접속하여 Google 계정으로 로그인하세요.

🚀 Firebase Console 열기
2

프로젝트 생성

  1. "프로젝트 추가" 버튼 클릭
  2. 프로젝트 이름 입력: defect-management
  3. Google 애널리틱스: 사용 안 함 선택
  4. "프로젝트 만들기" 클릭
3

Firestore 데이터베이스 생성

  1. 왼쪽 메뉴 → "Firestore Database" 클릭
  2. "데이터베이스 만들기" 클릭
  3. 보안 규칙: "테스트 모드에서 시작" 선택 ⭐
  4. 위치: "asia-northeast3 (Seoul)" 선택
  5. "사용 설정" 클릭
4

웹 앱 추가

  1. 프로젝트 개요 → 웹 아이콘 () 클릭
  2. 앱 닉네임: defect-app
  3. Firebase Hosting: 체크 안 함
  4. "앱 등록" 클릭
  5. 표시되는 Firebase 설정 코드 전체 복사
5

설정 코드 붙여넣기
